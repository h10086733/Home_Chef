# 社区家常饭界面与预约改造（2026-09-14）

## 定位与参考
用户提供六张 51 厨师截图：主页、找厨师、套餐、个人中心、详情信息和详情套餐。
借鉴分类入口、卡片、服务者详情和预约入口结构，使用原创奶油白/草绿样式。未复制竞品人物、菜品照片、品牌或评分。
面向普通家庭的日常用餐，支持擅长家常饭的居民（包括希望灵活增收的家庭主妇）申请成为服务者。职业称谓保持中性，不承诺收入。

## 已实现
- 首页三入口：找人做饭、家常套餐、做饭赚收入；四栏固定底部导航。
- 服务者名字/介绍/菜系搜索、菜系筛选和真实服务费排序；无结果提示。
- 套餐列表和独立服务者详情，服务范围、人工服务费与食材费用分开说明。
- 手艺与评价页读取现有评价接口，不使用接口中的默认五星作为评分，也不虚构服务次数。
- 三步预约：时间地址、用餐需求、费用确认；原报价、沙箱定金/全款接口与报价释放逻辑继续使用。
- 我的页面显示真实订单和可用券数量，并增加入驻/接单工作台入口。
- 服务者姓名图形、家常餐桌 CSS 插画作为占位，不伪装成真实人物或菜品照片。
