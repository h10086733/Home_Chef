## 下一步工作队列

1. **消息触达**：接单、支付、改约、服务提醒的微信订阅消息；先完成模板映射、用户授权、失败重试和幂等，模板 ID 等由平台准备。
2. **售后资金闭环**：裁定后剩余收入分配、已结算订单的追回/冲正、超期提现人工核查；明确权限和审计，不用“标记已处理”代替真实资金结果。
3. **真实部署验收**：正式服务器/域名、真实 AppID、支付商户绑定、转账场景/分账比例、回调及 worker，按小额订单逐项确认。
4. **运营保障**：日志留存与告警、备份恢复演练、异常订单处理与独立客服/财务账号配置。
5. **后续产品缺口**：短信入口、第三方实名、保险、更多片区及素材存储；这些需要外部能力或业务决定。

以上为接手排序建议，用户的新指令优先。不要因为本清单自动发送消息、扣款或申请外部服务。

- 历史增强需求对齐记录写“确认后检查结算资格，无额外固定等待期”；当前 chef-finance.ts 实施确认后至少 168 小时保护期，最高 720 小时。当前行为保留；调整需明确业务决策并覆盖售后与资金测试。
