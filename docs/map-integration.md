# 地图接入与启用

更新：2026-09-15。代码接入完成；尚未提供腾讯地图浏览器 Key，也未完成微信真机联调。

## 两端行为
- 微信小程序：Taro.chooseLocation 调用微信原生地图，返回地点名称、详细地址及 GCJ-02 经纬度；用户取消不改变原选择，权限拒绝时可自行打开设置。
- 网站与小程序 H5：共用腾讯位置服务地图选点组件，可搜索地点并选点；明确点击“确认这个位置”后才回填表单。无 Key 时显示未配置提示，不使用模拟地图或默认坐标。
- 用户地址：地图位置 + 用户补充的楼栋/单元/门牌号，拼接后通过原接口加密存储于 PostgreSQL；纬度/经度来自所选地点，用于后续服务半径校验。
- 服务者入驻：同样地图选择接单出发位置，代替原先固定默认坐标；完整出发位置不在公开厨师列表展示。
- 地图范围不等于服务开放范围。当前仍是长沙试运营，现有后端使用长沙坐标范围、运营片区与厨师半径进行校验；尚未实现行政区边界多边形自动归属。
- 坐标统一 GCJ-02，不把浏览器原始 WGS-84 定位结果直接用于距离计算。地图组件自行处理定位；允许用户不定位直接搜索。

## 启用网站和 H5
1. 在腾讯位置服务控制台创建应用，申请可用于网页地图选点组件的浏览器 Key，并配置对应授权域名。具体控制台授权要求以当前腾讯文档为准。
2. 将以下配置填入根目录 .env（.env.example 已提供空配置）：
   TENCENT_MAP_BROWSER_KEY=你的浏览器Key
   TENCENT_MAP_REFERER=你的应用名称
3. 重启 API 服务。前端通过已登录接口 GET /maps/config 获取这两项公开客户端配置，不需要重新构建。
4. 开发联调时按实际访问方式配置 localhost / 127.0.0.1；部署后配置实际网站和 H5 域名，使用 HTTPS。不要填入服务端 Secret、签名密钥或微信 AppSecret。
5. 网站“服务地址”和 H5“我的 → 服务地址”点击地图选址，搜索真实小区，确认地点、补充门牌号并保存。网络失败或 Key 授权失败时，可关闭地图检查配置后重试。

浏览器 Key 会发送给地图 iframe，是公开客户端配置；应在地图控制台限制其用途、授权域名和配额。项目不会读取或发送其他 .env 凭据。
腾讯选点组件协议与参数同时参考了已安装的 @tarojs/taro-h5 4.0.9 官方实现（chooseLocation.js）。

## 微信小程序
- 不需要通过网页 iframe 获取位置，使用微信原生地图接口。
- app.config.ts 已声明 requiredPrivateInfos: chooseLocation 及 scope.userLocation 用途说明。
- 替换 touristappid，使用真实小程序 AppID，在微信后台按实际用途配置位置接口能力、权限及用户隐私保护指引，核实账号可调用相关接口。
- 完成 API 的 HTTPS 域名部署与请求合法域名配置。
- 真机验证首次授权、拒绝/恢复授权、取消选址、搜索地点、保存地址及预约范围校验。这里只完成代码和编译，不代表微信审核或能力开通已经完成。
