## 尚未满足正式 v0.2 上线验收的部分

本地交易主链路可体验，但不能宣称完整 PRD 所有 P0 已通过：

1. 微信登录/手机号、实名与健康证明外部核验、微信支付回调/对账/多笔原路退款、真实保险、分账或提现渠道未接通。
2. 地图片区多边形、定位坐标系确认、容量候补、专业推荐榜单权重/反刷评、订阅消息渠道、培训考试和季度复审流程仍需扩展。
3. 当前只有新人基础券的开发活动，不是全部片区/节日/售后补偿券活动管理；优惠补贴采用明确的开发快照口径。
4. 图片为开发私有数据库存储，未接对象存储、病毒扫描和真实材料留存/删除管理；未提供图视频评价和完整内容申诉后台。
5. 临近取消与全款取消的收费映射、部分履约资金分配、结算后追偿等待发布规则或真实渠道的路径会阻断资金执行并保留工单，不按旧固定比例兜底。
6. 完整地区/日期 BI 筛选与导出、分级财务审批限额、生产审计存储隔离、备份恢复、容量压测、告警和值班演练尚未验收。
7. 开发账号角色由种子创建；尚无正式后台账号发放、敏感操作二次认证和组织级权限分配流程。

保留 BLK-REGION、BLK-ENTITY、BLK-PAY、BLK-CHEF-HEALTH、BLK-SETTLE、BLK-FOOD、BLK-RETENTION 门禁。不得将开发参数或沙箱成功状态解释为上述阻断项已经关闭。

## 运行约定

仅绑定本机。首批片区、示例地址、厨师和健康有效期都是开发数据。保留 .env 与 DATA_KEY；本地数据库数据在 Docker 命名卷中，重新启动不会清空。所有启动/构建/检查命令见根 README。
